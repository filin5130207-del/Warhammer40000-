# Warhammer 40,000 — Маркетплейс миниатюр

Платформа для покупки и продажи коллекционных миниатюр, фигурок и сопутствующих товаров по вселенной Warhammer 40,000.

---

## 👥 Пользовательские сценарии

### 1. Покупатель
- Просматривает каталог товаров по категориям.
- Ищет нужные миниатюры через строку поиска.
- Фильтрует товары по параметрам.
- Добавляет товары в корзину и оформляет заказ.
- Оценивает продавцов и оставляет отзывы.

### 2. Продавец
- Регистрируется и создаёт профиль магазина.
- Подаёт объявления о продаже миниатюр.
- Управляет своими товарами и ценами.
- Отслеживает заказы и общается с покупателями.
- Получает рейтинг от покупателей.

### 3. Администратор
- Модерирует объявления и пользователей.
- Управляет категориями и фильтрами.
- Разрешает спорные ситуации между покупателями и продавцами.
- Следит за соблюдением правил платформы.

## 🎨 Прототип интерфейса (первое ТЗ)

### Верхняя панель (header)
- **Логотип** (слева).
- **Вкладка с категориями товаров** (выпадающее меню).
- **Строка поиска** (по центру).
- **Выбор региона поиска** (рядом со строкой).
- **Кнопка входа / регистрации** (справа).
- **Кнопка подачи объявления** (справа, акцентная).

### Левая панель (фильтры)
- Ценовой диапазон (слайдер или поля от/до).
- Высота фигурки.
- Фракция (чекбоксы).
- Производитель (чекбоксы).
- Наличие (в наличии / под заказ).
- Покрашена ли фигурка (да / нет).
- Очки за юнита (диапазон).

### Основная область (каталог товаров)
- Сетка карточек товаров.
- Каждая карточка: фото, название, цена, продавец, рейтинг.

### Панель сортировки (под кнопкой входа)
- По рейтингу продавцов.
- По цене.
- По названию.
- По дате добавления.
